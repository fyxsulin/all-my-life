# 第 2 讲: 介绍Rust如何找到动态库

## 为什么要学习这节内容



## 在Rust中链接非标准位置的动态库有几种方法:

### 1. 使用 `LIBRARY_PATH` 环境变量:

```bash
export LIBRARY_PATH=/path/to/your/lib:$LIBRARY_PATH
```

Rust（rustc）在链接阶段会读取LIBRARY_PATH环境变量。具体来说：

- 编译期间(Compile-time)
  - LIBRARY_PATH用于静态链接库的查找
  - 影响rustc编译器的链接器查找库的路径
  - 主要用于解决`#[link]`属性和`-l`链接选项指定的库的位置
- 链接顺序
  - 首先检查build.rs中通过`cargo:rustc-link-search`指定的路径
  - 然后检查LIBRARY_PATH环境变量指定的路径
  - 最后检查系统默认路径(/usr/lib, /usr/local/lib等)

### 2. 在 `build.rs` 中指定链接路径

```rust
fn main() {
		println!("cargo:rustc-link-search=native=/path/to/your/lib");
}
```

解释一下build.rs

- 为什么需要build.rs
  - 它是Cargo构建系统的一个特殊文件
  - 用于处理那些在主代码编译之前需要完成的任务
  - 比如: 配置编译选项、生成代码、编译C代码等
- 谁在执行build.rs
  - Cargo 在编译主项目之前会自动检测并执行它
  - 执行顺序：build.rs -> 编译主代码 -> 链接
  - 它是作为一个独立的 Rust 程序被编译和运行的
- println! 的作用
  - println! 在 build.rs 中有特殊含义
  - 所有以 "cargo:" 开头的输出都是给 Cargo 的指令
  - Cargo 通过捕获这些标准输出来获取构建指令

### 3. 在`Cargo.toml`中配置链接

```toml
[build-dependencies]
pkg-config = "0.3"
```

解释一下上面的配置

- `[build-dependencies]`
  - 这是Cargo.toml中的一个段落标记
  - 专门用于声明构建脚本(build.rs)需要的依赖
  - 这些依赖只在构建时使用, 不会被编译进最终的程序
- `pkg-config = "0.3"`
  - 声明依赖pkg-config这个Rust库的0.3.x版本
  - 这个库提供了与系统pkg-config工具交互的能力
  - 让build.rs能够使用pkg-config来查找系统安装的库

完整的工作流程

```rust
// 1. 当你运行 cargo build 时

// 2. Cargo 看到 build-dependencies 中有pkg-config
// 这使得你可以在 build.rs 中这样使用:
// probe 这个单词的意思为 "搜寻"
fn main() {
  pkg_config::probe_library("libavformat").unwrap();
}

// 3. pkg-config会:
// - 查找系统中的libavformat文件
// - 找到后自动设置正确的编译器和链接器标志
```

## 总结

一般推荐使用build.rs加pkg-config的方式, 这样更加灵活且可移植.

## 扩展阅读

### Rust编译器(rustc)主要有以下几个编译阶段:

#### 1. 解析阶段(Parsing)

- 词法分析(Lexing)：将源代码转换成标记流(tokens)
- 语法分析(Parsing): 将标记流转换成抽象语法树(AST)

#### 2. 名称解析与宏展开 (Name Resolution & Macro Expansion)

- 处理导入(use)语句
- 解析标识符
- 展开宏(macro)代码

#### 3. HIR 生成 (High-level IR)

- 将 AST 转换为 HIR (高级中间表示)
- 进行类型推导
- 进行借用检查

#### 4. MIR 生成 (Mid-level IR)

- 将 HIR 转换为 MIR (中级中间表示)
- 进行借用检查
- 生命周期分析
- 优化代码

#### 5. LLVM IR 生成

- 将 MIR 转换为 LLVM IR
- 进行 LLVM 优化
- 生成机器码

#### 6. 链接阶段 (Linking)

- 链接外部库
- 生成最终的可执行文件或库文件

你可以通过以下命令查看编译的中间结果：

```bash
# 查看 HIR
rustc +nightly -Zunpretty=hir file.rs

# 查看 MIR
rustc +nightly -Zunpretty=mir file.rs

# 查看 LLVM IR
rustc --emit=llvm-ir file.rs
```

### 了解pkg-config命令

#### 1. pkg-config是什么？

- 是一个在编译程序时查找已安装库的工具
- 主要用在 Linux/Unix 系统中
- 可以告诉编译器库的位置和编译选项

#### 2. 基本用法

```bash
# 查看库的基本信息
pkg-config --list-all | grep FFmpeg    # 列出所有包含 ffmpeg 的库

# 检查某个库是否安装
pkg-config --exists libavformat
echo $?  # 0表示存在，1表示不存在

# 查看库的版本
pkg-config --modversion libavformat

# 获取编译参数
pkg-config --cflags libavformat        # 显示编译选项
pkg-config --libs libavformat          # 显示链接选项
```

#### 3. 常用选项组合

```bash
# 同时获取编译和链接选项
pkg-config --cflags --libs libavformat

# 检查版本要求
pkg-config --exists 'libavformat >= 58'
```

#### 4. pc文件

pkg-config 通过读取 .pc 文件获取库信息

这些文件通常位于：

```
/usr/lib/pkgconfig/
/usr/local/lib/pkgconfig/
```

#### 5. 在编译时使用

```bash
# 在编译命令中使用
gcc -o myprogram myprogram.c $(pkg-config --cflags --libs libavformat)
```
